# Shot Picker

AI로 뽑은 이미지가 든 폴더(여러 개 가능)를 열면 **파일 이름 앞의 샷 이름**으로 묶어서 샷별로 보여 주고,
마음에 드는 것만 골라 저장하면 첫 번째 이미지 폴더 안에 **`pick/`(고른 것)**, **`not_pick/`(안 고른 것)** 을 만들어 복사하는 툴입니다. 윈도우 / 맥 공용.

![icon](assets/ShotPicker.png)

## 다운로드
**[Shot Picker 받기](https://github.com/HsongLim/MagoTools/releases?q=shotpicker&expanded=true)** → 맨 위(최신 버전)에서 내 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 파일 |
|---|---|
| 윈도우 | `ShotPicker_Setup_<버전>.exe` → 더블클릭해서 설치 |
| 맥 (M1/M2/M3/M4) | `ShotPicker_<버전>_arm64.dmg` → 앱을 Applications로 끌어다 놓기 |
| 맥 (Intel) | `ShotPicker_<버전>_x86_64.dmg` |

- 윈도우에서 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
- 맥에서 "열지 않음" 경고가 뜨면 (처음 한 번만)
  - **시스템 설정 → 개인정보 보호 및 보안** → 아래쪽 **그래도 열기**
  - 또는 터미널에 `xattr -cr "/Applications/Shot Picker.app"`

## 사용법
앱 오른쪽 위 **?** 를 누르면 전체 설명서가 열립니다.

1. 이미지 파일 이름 맨 앞에 샷 이름을 넣기 (예: `EP01_S048_9040_v003_0012.png`)
2. **폴더 추가...** 로 이미지 폴더 넣기 (여러 개 가능, 하위 폴더까지 찾음, 창에 끌어다 놓아도 됨)
3. (선택) **원본 플레이트** 폴더 — Plate Exporter 로 받은 폴더 그대로 써도 됨
4. 왼쪽에서 샷 → 이미지가 **크게** 나옴 → ← → 로 넘기며 **클릭으로 고르기** (초록 테두리 + PICK)
5. **저장** → `첫번째폴더/pick/`, `첫번째폴더/not_pick/` 로 복사 (원본은 그대로)

| 키 | 동작 |
|---|---|
| 클릭 / 스페이스 | 고르기 켜고 끄기 |
| ← → / 휠 | 이전 / 다음 이미지 |
| ↓ / ↑ | 다음 / 이전 샷 |
| G | 썸네일 모아 보기 ↔ 크게 보기 |
| O | 원본 플레이트 켜고 끄기 (크게 보기에서는 나란히) |
| F | 크게 보기에서 원본으로 바꿔 보기 (같은 자리 깜빡 비교) |
| [ / ] | 이전 / 다음 샷 |
| Ctrl(맥 Cmd)+S | 저장 |

## 새 버전 내기 (관리자용)
1. `src/shot_picker.py` 의 `APP_VERSION` 올리기 + `CHANGELOG.md` 맨 위에 `## v버전` 추가
2. GitHub → **Actions → shotpicker → Run workflow** (또는 `shotpicker-v버전` 태그 올리기)
3. 10~20분 뒤 Releases 에 설치 파일 3개가 올라가고, 설치된 앱이 켤 때 업데이트를 알려 줍니다
