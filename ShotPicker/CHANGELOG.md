# 변경 기록
릴리스할 때 맨 위에 `## v버전` 항목을 추가하면 그 내용이 앱의 업데이트 안내 창에 표시됩니다.

## v1.1.1
- 크게 보기에서 ↓ = 다음 샷, ↑ = 이전 샷 (← → 는 같은 샷 안에서 이미지 넘기기)

## v1.1.0
- 이미지 폴더를 여러 개 넣을 수 있음 (흩어진 이미지도 샷 이름이 같으면 한 샷으로 모아 봄)
  - 저장은 첫 번째 폴더 안 pick / not_pick 으로 모두 모음
- 기본 화면을 크게 보기로: 이미지 한 장을 크게, 아래 줄에 같은 샷 이미지들
  - 클릭 / 스페이스 = 고르기, ← → / 휠 = 넘기기, G = 썸네일 모아 보기
- 원본 플레이트는 처음엔 꺼 두고 O 로 켬 (켜면 원본 / AI 나란히)

## v1.0.0
- 첫 배포: 이미지 폴더를 파일 이름 앞의 샷 이름으로 묶어 샷별 썸네일 보기
- 클릭으로 고르기, 크게 보기(← →), 원본 플레이트 켜고 끄기(O), 원본으로 바꿔 보기(F)
- 저장: 고른 것 -> pick , 안 고른 것 -> not_pick 로 복사 (원본은 그대로), 고른 내용 자동 기억
- 앱 안에서 업데이트 (켤 때 자동 확인, "업데이트 확인" 버튼)
