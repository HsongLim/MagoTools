Guide Maker 사용법
==================

1. 이미지 불러오기
   - [이미지 불러오기] (한 장 / 여러 장) 또는 [폴더 불러오기]
   - 이미지 파일이나 폴더를 창에 끌어다 놓아도 됩니다
   - 지원: jpg, png, tif, bmp, webp, tga  (EXR은 지원 안 함)
2. 왼쪽 = 원본, 오른쪽 = 가이드를 그리는 곳
3. 도구: 펜 / 박스 / 채운 박스 / 직선 / 화살표 / 그리드 / 글자 / 지우개
   - 색: [색] 버튼 또는 빠른 색 버튼,  투명도 5~100%,  굵기 1~60
   - 그리드
       드래그해서 만들기 -> 네 모서리 손잡이를 끌면 원근에 맞게 모양이 바뀜 (코너핀)
       안쪽을 잡고 끌면 통째로 이동
       Shift 를 누른 채 코너를 끌면 모양 그대로 크기 조절
       선택한 그리드의 변 가운데 동그라미를 끌면 그 변만 밀고 당기기
       그리드 위에서 마우스 휠을 굴리면 가운데 기준으로 확대 / 축소
       위쪽 [그리드 칸 가로 / 세로]로 칸 수 설정 (기본 10 x 10, 선택한 그리드에 바로 적용)
       [선 굵기]로 그리드 선 굵기 설정 (실제 이미지 픽셀 기준, 기본 2px)
   - 그리드를 선택한 채 색 / 굵기 / 투명도를 바꾸면 그 그리드에 바로 적용
   - 글자
       이미지 위를 클릭하면 그 자리에서 바로 입력 -> 다른 곳을 클릭하거나 Esc 로 끝
       글자를 끌면 이동, 오른쪽 아래 네모 손잡이를 끌면 크기 조절
       글자를 두 번 클릭하면 고치기 (모두 지우면 삭제)
       새 글자의 크기, [글자 테두리]는 위쪽에서 설정
       글자 위에서 마우스 휠을 굴려도 크기 조절
   - 지우개: 지우고 싶은 가이드를 클릭하면 그것 하나만 지워짐 (마우스를 올리면 빨간 테두리로 표시)
   - 선택한 그리드 / 글자는 Delete 키로도 지울 수 있음.  지운 것도 Ctrl+Z 로 되돌리기
4. 아래쪽 [저장 폴더]를 지정하고
   - [현재 이미지 내보내기]: 지금 보고 있는 이미지만
   - [전체 내보내기]: 불러온 이미지 전부 (가이드 그린 것만 고를 수도 있음)
5. 파일 이름은 원본이름_guide.확장자 로 저장됩니다.
   예) shot_0010.png -> shot_0010_guide.png   (원본 해상도 그대로)

업데이트
  프로그램을 켤 때 새 버전이 있으면 창이 뜹니다. [예]를 누르면 알아서 설치하고 다시 켜집니다.
  오른쪽 위 [업데이트 확인] 버튼으로 직접 확인할 수도 있습니다.

단축키
  Ctrl+O  이미지 불러오기        Ctrl+E  현재 이미지 내보내기
  Ctrl+Z  되돌리기               Ctrl+Y  다시 실행
  ← / →   이전 / 다음 이미지
  1~8     도구 선택 (펜, 박스, 채운 박스, 직선, 화살표, 그리드, 글자, 지우개)
  Delete  선택한 그리드 / 글자 지우기
  [ / ]   굵기 줄이기 / 늘리기

처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] -> [실행]을 누르세요.
문제가 생기면 사용자 폴더의 guide_maker_error.txt 를 보내주세요.
