Guide Maker 사용법
==================

1. [이미지 열기] 또는 [폴더 열기]로 이미지를 불러옵니다. (한 장 / 여러 장 모두 가능)
   - 지원: jpg, png, tif, bmp, webp, tga  (EXR은 지원 안 함)
2. 왼쪽 = 원본, 오른쪽 = 가이드를 그리는 곳
3. 위쪽 도구: 펜 / 박스 / 채운 박스 / 직선 / 화살표
   - 색: [색 선택] 버튼 또는 빠른 색 버튼
   - 투명도: 5~100%, 두께: 1~60
4. 아래쪽 [저장 폴더]를 지정하고
   - [현재 이미지 내보내기]: 지금 보고 있는 이미지만
   - [전체 내보내기]: 불러온 이미지 전부 (가이드 그린 것만 고를 수도 있음)
5. 파일 이름은 원본이름_guide.확장자 로 저장됩니다.
   예) shot_0010.png -> shot_0010_guide.png
   원본 해상도 그대로 저장됩니다.

단축키
  Cmd+O  이미지 열기          Cmd+E  현재 이미지 내보내기
  Cmd+Z  되돌리기             Cmd+Y  다시 실행
  ← / →   이전 / 다음 이미지
  1~5     도구 선택 (펜, 박스, 채운 박스, 직선, 화살표)
  [ / ]   두께 줄이기 / 늘리기

문제가 생기면 홈 폴더의 guide_maker_error.txt 를 보내주세요.

설치: "Guide Maker" 앱을 옆의 Applications 폴더로 끌어다 놓으세요.
처음 열 때 "열지 않음" / "확인되지 않은 개발자" 경고가 뜨면 (한 번만 하면 됨):
  방법 1) [완료] -> 시스템 설정 -> 개인정보 보호 및 보안 -> 아래쪽 [그래도 열기]
  방법 2) 터미널에 붙여넣기:  xattr -cr "/Applications/Guide Maker.app"
