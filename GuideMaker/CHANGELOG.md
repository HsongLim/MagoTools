# 변경 기록

## v1.1.5
- 내보내기 미리보기: 가이드만 / 원본 + 가이드 붙이기 / 둘 다, 배치·구분선·이름표를 바꾸면 저장될 모습이 작게 보임
- 업데이트 확인 오류 수정: 회사 프록시가 GitHub 을 막을 때(Tunnel connection failed: 403) 컴퓨터 기본 인터넷 설정 / 바로 연결로 다시 시도

## v1.1.4
- 선택 도구 추가: 모든 가이드(펜, 박스, 직선, 화살표, 그리드, 글자)를 클릭해서 선택 → 끌어서 이동, 손잡이로 크기 / 모양, 휠로 확대·축소, Delete·Backspace 로 지우기
- 화살표 / 직선: 양 끝 점을 끌어서 방향과 길이 바꾸기
- 어느 도구에서든 Ctrl(맥은 Cmd) + 드래그로 화살표 그리기
- 선택한 가이드의 색 / 투명도 / 굵기 / 글자 크기 / 글자 테두리를 바로 바꾸기
- 그리기 도구에서도 이미 있는 가이드를 클릭하면 선택 (드래그하면 새로 그리기)
- 글자 테두리 기본값: 꺼짐
- 창 크기를 줄이면 도구 막대가 다음 줄로 넘어가서 모든 버튼이 보이게
- 오른쪽 아래 ? : 마우스를 올리면 요약, 누르면 설명서 창
- 맥: 색 칸이 흰색으로만 보이던 문제 수정
- 맥 / 윈도우: 한글 입력 상태에서도 Cmd / Ctrl + Z 같은 단축키가 동작
- 도구 번호가 바뀜: 1 선택, 2 펜, 3 박스, 4 채운 박스, 5 직선, 6 화살표, 7 그리드, 8 글자, 9 지우개 (V 도 선택)

## v1.1.3
- 원본 + 가이드를 붙여서 내보내기 (`이름_compare`): 좌우 / 위아래, 구분선·이름표 켜고 끄기, 가이드만 / 붙인 것만 / 둘 다 선택

## v1.1.2
- 그리드 크기 조절: Shift + 코너 끌기(반대쪽 코너 기준, 모양 유지), 변 가운데 손잡이로 한 변만 밀고 당기기, 마우스 휠로 가운데 기준 확대/축소
- 글자 위에서 마우스 휠로 크기 조절
- 지우개 도구: 클릭한 가이드 하나만 지우기 (마우스를 올리면 지워질 대상 표시)
- 선택한 그리드 / 글자를 Delete 키로 지우기
- 지운 것도 되돌리기로 살릴 수 있음

## v1.1.1
- 글자: 입력 창 없이 이미지 위를 클릭한 자리에서 바로 입력
- 글자를 끌어서 이동, 오른쪽 아래 손잡이로 크기 조절, 두 번 클릭해서 고치기
- 그리드 기본값을 얇은 선(2px) · 10×10 칸으로
- 그리드 선 굵기를 따로 설정 (실제 이미지 픽셀 기준 1~50px, 선택한 그리드에 바로 적용)
- 굵기는 도구마다 따로 기억
- 그리드를 선택한 채 색 / 굵기 / 투명도를 바꾸면 그 그리드에 바로 적용
- 마우스를 올린 곳에 따라 커서 모양이 바뀜 (글자 입력, 이동, 크기 조절)

## v1.1.0
- 그리드 도구: 드래그로 만들고, 네 코너를 잡아 원근에 맞게 모양 바꾸기(코너핀), 안쪽을 잡고 이동, 가로/세로 칸 수 설정
- 글자 도구: 클릭해서 글자 넣기 (여러 줄, 크기, 테두리), 넣은 글자를 다시 누르면 고치기
- 이미지 파일/폴더를 창에 끌어다 놓아서 열기
- 앱 안 업데이트: 켤 때 새 버전이 있으면 알려주고, 누르면 받아서 설치 후 다시 켜짐
- 입력칸에 글자를 칠 때 단축키가 같이 동작하던 문제 수정

## v1.0.0

- 색 선택, 투명도, 두께 조절, 되돌리기 / 다시 실행
- 원본 해상도로 `<원본이름>_guide.<확장자>` 내보내기 (현재 이미지 / 전체)
