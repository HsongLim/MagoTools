## 새 버전 / 새 툴 (관리자용)
- 툴마다 태그 이름이 다릅니다: `guidemaker-v1.1.0` 처럼 `<툴이름>-v<버전>`
- 태그를 올리면 그 툴만 윈도우 / 맥 설치 파일이 자동으로 만들어져 Releases에 올라갑니다
- 자세한 방법은 각 툴 폴더의 README 참고
